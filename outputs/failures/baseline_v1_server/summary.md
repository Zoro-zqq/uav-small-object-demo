# 失败案例自动诊断（候选，不代替官方指标）

使用完整 548 张验证图的预测存档，展示阈值 score>=0.25。先匹配同类 IoU>=0.5，再配异类 IoU>=0.5，最后配同类 0.1<=IoU<0.5；各框最多配一次。
错类、定位候选单独计数，剩余框才计未匹配，因此下表不能直接当作常规 FN/FP。高密度重叠框的配对存在歧义。
原始忽略区域未进入真实标签，未匹配预测可能是忽略目标或漏标，不能直接全部归因为背景误检。低于阈值的预测视为未显示；未匹配真实框不代表模型在任何阈值下都找不到它。

本地可视化数据检查：{'content_fingerprint_matches': True, 'target_coordinates_match': True}。若内容指纹未确认一致，局部图只作初步复核，最终在训练服务器相同数据上重生成；汇总数字始终来自服务器保存的真实框与预测，不受本地图片影响。

## 可以与不可以下的结论

可报告固定阈值下的错误数量、类别混淆方向及目标尺寸；不能仅由框匹配推断是缩放、遮挡、样本不均衡或标注错误导致，也不能将类别汇总差异解释为因果。
人工只需优先复核这十张局部对照卡：左侧真实框、右侧预测框，重点框线加粗；裁剪和放大仅用于展示，不代表模型实际输入。
