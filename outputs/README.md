# 实验产物

历史文件保留原路径与原内容。本目录存放运行自动生成的文件，人工结论写入`docs/reports/`并链接对应证据。

| 子目录 | 用途 |
|---|---|
| checkpoints | 权重、训练曲线、args与训练日志 |
| metrics | 验证JSON、尺寸分组指标及原始预测存档 |
| failures | 失败案例统计、图卡与人工复核 |
| dataset_statistics | 数据分布统计与图表 |
| predictions | 推理或抽样叠框 |
| logs | 命令执行日志 |

每次实验使用唯一名称，不覆盖用于汇报的历史结果。原始数据放项目外。新产物默认被git忽略，已跟踪的历史文件不因此自动取消跟踪。
